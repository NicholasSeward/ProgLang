# Reading Assignments

**Textbook:** Sebesta, *Concepts of Programming Languages*, 12th ed.  
Complete each week’s reading **before** that week’s class meetings unless noted otherwise.

**Key:** Required reading supports lectures and assessments. Optional reading is recommended background and is not examined in depth.
